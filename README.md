# Maketik

Studio personnel de création de vidéos courtes.

## Première boucle en construction

1. Créer un projet.
2. Choisir un univers graphique propre au projet.
3. Choisir puis verrouiller un personnage récurrent.
4. Ajouter plusieurs liens TikTok comme références éditoriales.
5. Ajouter une source YouTube.
6. À venir : ingestion/transcription, analyse éditoriale, angles, scripts, validation, voix française, plan visuel, recherche de références et génération d'illustrations.
7. Export des éléments pour montage manuel dans CapCut.

## Invariants

- Un projet peut produire plusieurs scripts, audios et jeux d'images.
- Univers et personnage sont définis au niveau du projet, pas globalement.
- Les références TikTok servent à analyser des mécanismes éditoriaux; les nouveaux scripts restent originaux.
- La source YouTube est la matière factuelle à exploiter.
- Les étapes créatives importantes restent validables avant progression.
- L'absence d'un service IA/voix externe ne doit pas détruire les données du projet.

## Lancer en local

```bash
npm install
npm run dev
```
